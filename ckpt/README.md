# Required checkpoint files

Download these files from the official Hugging Face repository:

https://huggingface.co/Alibaba-DAMO-Academy/RADAR

Required for the inference UI:

```text
ckpt/
├── checkpoint_radar_pretrain.pth
├── infer_text_embedding_radar.pt   # included in this Git repository
└── bert-base-chinese/
    ├── config.json
    ├── config_decoder.json
    ├── pytorch_model.bin
    ├── tokenizer.json
    ├── tokenizer_config.json
    └── vocab.txt
```

Large model files are excluded from GitHub.
